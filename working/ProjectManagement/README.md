- Roadmap / Phase 規劃
- Release Planning
- Function 開發排序
- Dependency / Milestone
- Risk / Blocker
- 開發準備與追蹤

原則：
- 本目錄不是正式 SSOT。
- 已確認並進入執行的項目，應同步到 `execution/BACKLOG.md`、`execution/SPRINT.md` 或其他正式執行文件。
